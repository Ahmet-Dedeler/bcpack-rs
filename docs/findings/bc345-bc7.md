# Findings: block rebuild for BC3, BC4, BC5 and BC7 (branch `bc5-bc7`, work in progress)

2026-11-24. Numbers are on retail Xbox Series texture stores read in place (46 main + 11 content-pack stores);
nothing derived from them is committed except fitted table values. "Reference" is a third-party decoder used only to
measure (never as a source of table values).

## What is in the tree

- `src/format.rs`: modes, lane widths, the two references of a record, the dictionary addressing.
- `src/bcn.rs`: BC3 / BC4 / BC5 rebuild (endpoint and index states summed against two references).
- `src/bc7.rs`: BC7 rebuild (8-bit top-aligned endpoint state, 4-bit top-aligned index state, control codes), block
  pack and unpack.
- `data/bc3.json`, `bc4.json`, `bc5.json`, `bc7.json`: the tables that could be determined from data (below).
- `tests/modes.rs`: synthetic tests. No stream encoder for these modes yet, and they are not wired into the CLI,
  `src/texture.rs` or the Python mirror.

## Rules: exact

With the reference's tables converted in memory, the rebuild is byte-identical to the reference on every chunk of every
store: BC4 77 chunks / 201,728 blocks, BC5 333 / 4,890,368, BC3 35 / 660,992, BC7 5,167 / 80,055,040; 0 differing
blocks. (All chunks, so this is a check of the rules, not of fitted values.) Facts used: lane widths and two symbols
per lane for 16-byte blocks; index reference = lane 1, endpoint reference = lane 1 + unzigzag(lane 0); references
past the chunk start read a 255-entry dictionary; states and residual rules as described in the module docs.
In retail data BC1, BC3, BC4 and BC5 never use the index reference (lane 1 is always 0), so the index half of their
dictionaries is never read; BC7 uses both.

## Tables solved from data

| table | method | result against the reference |
|---|---|---|
| BC4, BC5, BC3-alpha pair ranks (64 each) | substitution cipher: bigram likelihood of the index symbols against pair patterns counted on the plain mips of the same textures; swap search plus exhaustive re-arrangement of 7-symbol subsets | 64/64 each. Smallest swap margin 722 (BC4), 3,618 (BC3), 77,134 nats (BC5) |
| BC7 control codes, modes 1, 3, 4, 5, 6, 7 (205) | rank order ((E+1)(O+1), E) of the 285 lane-15 pairs; mode from lane widths gives runs 7x64, 6, 5x4, 4x8, 3x64, 2x22, 1x64, 0x14, 2x42, 0x2; partitions descend inside a run and the anchor rule (0 top bits on blocks whose index chain is table-free) leaves exactly one assignment for modes 7, 3, 1; rotation from the wide lane; index selection from which index set is all zero when the scalar endpoints are equal | 205/205 |

The population matters for the cipher: counted on all plain blocks of a format instead of the same textures' mips,
BC4 comes out wrong in 47-64 symbols (BCPack BC4 is UI art).

## Not determined (shipped as `null`, counted in `unfitted_blocks`)

- **BC7 control codes of modes 0 and 2 (80).** The anchor rule leaves 6 and 72 assignments. Picking by an index
  smoothness score across subset borders gets 78 of 80 right (two mode-2 codes swapped, score margin 25), so they are
  left out.
- **BC3 colour quadrant ranks (256).** The BCPack BC3 textures do not share the plain textures' pattern statistics
  (their most common quadrant is the complement of the plain one), the complement was fixed by edge continuity, and
  199 of 256 came out right. Not good enough to ship.
- **Dictionaries, all four modes.** Blocks rooted at one entry are known up to that entry's values, and no exact
  rule pins those. Tried for BC5: (a) equality with stream neighbours: biased, because a block that equals its
  neighbour would have referenced it (most entries off by about (-3, +3)); (b) pixel continuity across block edges
  with a kernel counted on plain data: off by up to 40; (c) the same with kernels counted inside the BCPack chunks,
  conditional on the pixel's position and the block's range: 61 of 428 entry halves exact, 135 within 1, 52 % of
  rooted half-blocks on exact values. Statistics get close but not exact; none of these fits is in the tree.
  BC7's dictionary was not attempted.
